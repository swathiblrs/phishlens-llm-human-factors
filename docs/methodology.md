# Two-stage methodology

## Stage 1: multimodal LLM robustness evaluation

1. Prepare verified legitimate and phishing website screenshots.
2. Apply controlled, human-visible modifications to selected phishing screenshots.
3. Evaluate original and modified samples using the same versioned prompt.
4. Measure classification performance and explanation quality by modification type.
5. Identify matched correct and incorrect LLM outputs for possible study stimuli.

Modification categories will be finalized with the instructor. Initial candidates include:

- logo removal or visible logo changes
- color and layout changes
- visible brand or URL cue changes

## Stage 2: human study

Use selected Stage 1 outputs to compare participant decisions under defined assistance conditions. The main factors should remain focused, such as assistance type and AI correctness. Modification type can be recorded for secondary analysis without making the study design unnecessarily complex.

No participants should be recruited until the team receives the applicable instructor and IRB/HRPP guidance.
